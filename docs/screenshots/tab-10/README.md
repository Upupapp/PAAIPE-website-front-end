# Tab 10 evidence — Concept UI

`/partners`, `/responsible-ai`, `/contact`, `/privacy`, `/terms` and
`/accessibility`, captured 2026-09-03 from the production build. Desktop
1440×900 (Chromium), mobile 390×844 (WebKit), full page, under
`reducedMotion: 'reduce'`.

What to check in each:

- **privacy / terms** — the DRAFT FOR REVIEW banner is the first thing on the
  page, before the heading, and every unsupplied value is a bracketed
  monospace token. The count at the top says how many remain (16 and 15). These
  pages cannot be mistaken for finished legal text, which is the point.
- **partners** — no organisation is named, no logo appears, and the caveat
  _"Listing a category does not indicate an existing partnership"_ sits directly
  under the category list.
- **responsible-ai** — an explicit "Educational, not a certification" panel.
- **contact** — no form at all, not even a disabled one, and no invented
  address, phone number or response time.
- **accessibility** — a goal statement with an explicit "not a claim of
  conformance" note, and a list of what is actually measured on every build.
