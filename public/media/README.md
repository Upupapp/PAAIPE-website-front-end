# Approved public visual assets

Editorial and decorative imagery approved for public use.

- Every image needs confirmed usage rights before it is added.
- Decorative map / network / node graphics live here and must be kept visually
  distinct from the official logo (`public/brand/`).

## What is here

### `ph-contour.svg` — generated, public domain

The decorative Philippine contour used in `NetworkField`'s `map` slot on the
home hero. **It is not hand-drawn**, which was the whole of B-6's objection: an
approximated national outline is a credibility risk for a Philippine
association.

- **Source:** Natural Earth 1:50m Admin 0 – Countries, retrieved 2026-09-04.
- **Licence:** public domain. Natural Earth states "All versions of Natural
  Earth raster + vector map data found on this website are in the public
  domain", that no permission is needed, and that attribution is unnecessary.
  Derivative and commercial use are explicitly permitted.
- **Vendored input:** `scripts/data/ph-outline.geojson` — the Philippines
  feature only, so a build never depends on a network call.
- **Generated by:** `npm run media:contour`. Verified by `npm run media:check`,
  which is part of `npm run check`, so the asset cannot drift from its source.
- **Reduction:** Ramer–Douglas–Peucker at a stated tolerance. Every point drawn
  is a real coordinate from the source; none is invented, moved or smoothed.

**It is decoration, not a statement of territorial extent.** It draws the
archipelago as Natural Earth maps it, at one stated resolution, and takes no
position on any maritime or territorial question. It is `aria-hidden`.
